# InsightBoard — Business Analytics Dashboard

A responsive, interactive business dashboard built with **HTML, CSS and vanilla JavaScript**. Designed as a client-facing portfolio demo, with no backend or external libraries.

## Live demo
After enabling GitHub Pages from the main branch (root), visit:
https://gahejodev.github.io/bussiness-analytics-dashboard/

## Features
- KPI cards for revenue, orders, average order value, profit and margin
- Interactive 7-day / 30-day / 90-day time filters
- Revenue trend chart (accessible SVG)
- Sales breakdown by category and channel
- Inventory alerts and recent order table
- CSV export of filtered orders
- Responsive desktop and mobile layout
- Local demo dataset; no network calls

## How to run
Open `index.html` in a modern browser. To publish, use **Settings → Pages → Deploy from a branch → main → /(root)**.

## Important
All figures are **fictional sample data** generated locally for demonstration. This project is not connected to a real shop, payment provider or live inventory database. For production, integrate authenticated APIs, access controls and a persistent database.
